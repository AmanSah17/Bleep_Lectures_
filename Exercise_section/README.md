# Python fundamentals exercises

This folder contains [`Exercise_1_Python_Fundamentals_Exercise_Problems.ipynb`](Exercise_1_Python_Fundamentals_Exercise_Problems.ipynb), a hands-on notebook designed to reinforce concepts introduced in the Python fundamentals lessons.

## Topics covered

- Variables and arithmetic expressions
- Strings, indexing, and slicing
- Conditional statements
- Loops and basic program logic

The notebook presents beginner-friendly problems with explanations and code cells. It is most useful after completing the introductory lessons in [`../notebooks/`](../notebooks/). The root [README](../README.md) contains setup instructions and a suggested course sequence.

## Practice workflow

1. Read the problem statement and identify the input, expected result, and concepts involved.
2. Write and run your own solution in a new code cell before changing the provided cells.
3. Compare the result with the explanation and test additional values where possible.
4. Restart the kernel and run all cells to check that the notebook works in order.

Open the notebook in Jupyter Notebook, JupyterLab, or a compatible editor. If necessary, install Jupyter with `python -m pip install notebook`.
