# Python lesson notebooks

This folder contains the guided lessons and practice notebooks for Bleep Lecture 0. Notebooks are self-contained Jupyter documents; for setup instructions and the overall course overview, see the [repository README](../README.md).

## Recommended order

| Order | Notebook | Focus |
| --- | --- | --- |
| 1 | [`02_1a_Python_Foundations_01.ipynb`](02_1a_Python_Foundations_01.ipynb) | Introductory Python foundations and code examples |
| 2 | [`Step_1_1b_Python_Foundations_02.ipynb`](Step_1_1b_Python_Foundations_02.ipynb) | Strings and text manipulation |
| 3 | [`1_Python_datatypes_and_functions.ipynb`](1_Python_datatypes_and_functions.ipynb) | Python data types and functions |
| 4 | [`1_Python_Programming_Fundamentals_Complete.ipynb`](1_Python_Programming_Fundamentals_Complete.ipynb) | A more complete fundamentals walkthrough |
| 5 | [`02b-Python Crash Course Exercises.ipynb`](02b-Python%20Crash%20Course%20Exercises.ipynb) | Exercises for reinforcing introductory concepts |
| 6 | [`02c_Modules_in_Python.ipynb`](02c_Modules_in_Python.ipynb) | Importing and working with modules |
| 7 | [`02d_Working_with_Files_in_Python.ipynb`](02d_Working_with_Files_in_Python.ipynb) | Reading, writing, and managing files |

The sequence is a suggestion rather than a strict prerequisite chain. The complete fundamentals notebook can be used as a review, and the modules and file lessons may also be opened independently.

## How to use these lessons

1. Open a notebook using Jupyter Notebook, JupyterLab, or a compatible editor.
2. Read each markdown section before running its code.
3. Run cells from top to bottom to preserve the expected execution state.
4. For practice cells, attempt your own solution before consulting any existing output.
5. Restart the kernel and select **Run All** to confirm a notebook works from a clean state.

Install Jupyter if needed with `python -m pip install notebook`, then run `jupyter notebook` from the repository directory. The notebooks primarily use Python's standard library.
