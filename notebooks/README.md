# Python lesson notebooks

This folder contains the guided lessons and practice notebooks for Bleep Lecture 0. Notebooks are self-contained Jupyter documents; for setup instructions and the overall course overview, see the [repository README](../README.md).

## Recommended order

| Section | Notebook | Focus |
| --- | --- | --- |
| 1a | [`02_1a_Python_Foundations_01.ipynb`](02_1a_Python_Foundations_01.ipynb) | Python introduction, syntax, variables, and foundational examples |
| 1b | [`1b_Python_Foundations_02.ipynb`](1b_Python_Foundations_02.ipynb) | Strings, lists, indexing, slicing, and related operations |
| 2a | [`1_Python_datatypes_and_functions.ipynb`](1_Python_datatypes_and_functions.ipynb) | Python data types, collections, and functions |

The section order is a recommended path rather than a strict prerequisite chain. Section 2c is listed for clarity but its modules lesson is not currently present. The two complete fundamentals notebooks—[`1_Python_Programming_Fundamentals_Complete.ipynb`](1_Python_Programming_Fundamentals_Complete.ipynb) and [`Python_Programming_Fundamentals_Complete.ipynb`](Python_Programming_Fundamentals_Complete.ipynb)—can be used as broader reviews. The object-oriented and file lessons may also be opened independently.

## How to use these lessons

1. Open a notebook using Jupyter Notebook, JupyterLab, or a compatible editor.
2. Read each markdown section before running its code.
3. Run cells from top to bottom to preserve the expected execution state.
4. For practice cells, attempt your own solution before consulting any existing output.
5. Restart the kernel and select **Run All** to confirm a notebook works from a clean state.

Install Jupyter if needed with `python -m pip install notebook`, then run `jupyter notebook` from the repository directory. The notebooks primarily use Python's standard library.
